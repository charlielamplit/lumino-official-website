## 2. 单篇文章建议结构

每篇保持同一骨架，便于中英对照与后续 CMS：

1. **标题**：问题 / 结论导向
2. **导语**：80-120 字说清读者与收益
3. **适用**：行业 / 角色 / 场景 / 时限
4. **核心判断**：用条目回答「先做什么、不必做什么」
5. **关联服务**：CBAM / PCF / ESG / GHG / EAC / TRADE
6. **落地步骤**：3-5 步可执行
7. **常见卡点**：资料缺口 / 口径争议
8. **法规与标准锚点**：名称 + 版本或年份（如 2026-Qx）
9. **延伸阅读**：站内相关文章 URL（至少 1 篇）
10. **咨询转化**：
    - 说明何时该约咨询
    - 建议携带 / 提前准备的资料
    - 联系入口
    - 不替代法律意见或法定申报义务
11. **元数据**：行业标签、服务标签、更新日期

正文字数建议 **800-1500 汉字**；英文稿约 600-900 词。超过 2000 字拆成系列。

## 3. 首页与知识库列表展示规则

首页 Insights 区：

- 展示最新 3 篇（或手工置顶 1 篇 + 最新 2 篇）
- 卡片字段：类型标签 + 标题 + 一句导语；点击进全文

知识库列表页：

- 筛选项至少：**3 个行业 + 服务标签 + 搜索 URL**（可先静态）
- 无结果时给 3 条推荐文，避免空态

## 4. 写作与 AI 约束

- 不堆法规条文；先给判断与动作
- 数字、时限、编码以原文库为准，不确定处标 `[待核]`
- 不抄竞品站点段落；可参考结构不可复述原文
