# 知识库资料库（Knowledge library）

本目录存放官网「行业知识库」撰稿用的**法规与标准原文**。

| 路径 | 说明 |
|---|---|
| `sources/` | 按主题分类的源文件（PDF / DOCX） |
| `INDEX.md` | 分类清单与文件名索引 |
| `../knowledge-content-brief.md` | 对外文章选题、结构与写作规范 |

## 目录约定

- **不要**把源 PDF 放在 `apps/knowledgebase/`（那是运行时应用目录，易与可发布站点混淆）。
- 源文件默认 **gitignore**，避免把数百 MB 二进制推进远程；需要同步时用网盘 / 对象存储，并保持本 INDEX 与文件夹一致。
- 对外可读的 Insights 文章草稿应放在 `apps/site/knowledge/` 或后续 CMS，不与原文混放。
