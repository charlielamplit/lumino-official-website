# CBAM 首次进入与二级导航收口实施 Plan

> 实施说明（2026-11-16）：首次进入原型已落地。未授权用户先进入服务启动授权；授权后创建年度项目并启动收资；Agent 仅在年度项目进入收资后启用，不参与服务授权，也不在未完成向导中出现。跨年度和并行工作规则以 `2026-11-16-cbam-cross-year-agent-plan.md` 为准。

关联 Issue：[#71](https://github.com/charlielamplit/lumino-official-website/issues/71)

## 目标

让零项目客户、已授权但未建年度项目的客户、以及已进入执行期的客户分别落到正确起点；将 CBAM 的持久二级导航收口为五项，同时确保旧页面中的业务能力被迁移或降级访问，而不是因导航合并而丢失。

## 已确认信息架构

激活后的五个二级入口：

1. 当前工作
2. 年度项目
3. 产品与设施
4. 数据与核算
5. 报告与交付

“全年流程”保留为当前工作中的次级完整流程；“监测计划”并入年度项目；“季度数据”和“计算与成本”并入数据与核算。旧 route 在本轮保留兼容入口，避免书签或任务跳转失效。

## 执行顺序

### 1. 服务启动授权与首次进入

- 复用 `serviceOrder` 状态机表达合同后、系统激活前的线上授权链。
- 增加“服务启动”原型状态页，明确授权年度、服务范围、双方角色和等待对象。
- 路由规则：未 ACTIVE → 服务启动；ACTIVE 且无年度项目 → 年度项目；项目可执行 → 当前工作。
- 不以角色切换代替授权，不在未激活状态展示空执行页。

### 2. 五项持久导航与兼容路由

- CBAM 服务导航只展示五项。
- 保留 `roadmap`、`monitoring-plan`、`data`、`results` 等旧 route，由新页面内部动作继续访问或重定向。
- 当前工作增加年度阶段摘要和“查看完整流程”。

### 3. 年度项目整合页

- 未建项目时展示五步向导；草稿恢复上次步骤。
- 已建项目后展示范围、角色、监测计划和关键日期摘要。
- 监测计划保留完整详情和状态动作，由年度项目进入。
- 年度范围只引用产品与设施的受控版本，不复制长期主档。

### 4. 产品与设施核心工作页

- 页面内分为：产品与 CN 编码 / 设施与生产路线 / 导入与变更记录。
- 产品名称、CN Code、适用性、设施和路线可被维护。
- Excel 导入先形成字段差异提案；Agent 建议与已确认值分层展示；具名用户确认后才进入受控版本。
- 已被年度项目引用的变更展示影响预览，锁定年度不被追溯覆盖。

### 5. 数据与核算整合页

- 页面内分为：材料与数据 / 计算结果 / 成本情景。
- 保留现有数据缺口、上传确认、计算版本、阻塞项和情景对比内容。
- 从当前工作和任务入口进入时，默认打开与任务对应的内部页。

### 6. 内容迁移核对

- 逐项核对 Issue #71 的迁移矩阵。
- 删除范围只限重复入口、重复摘要、无对象支撑的占位内容。
- 团队与权限继续属于全局企业设置；CBAM 页面只展示项目角色摘要。

### 7. 验证

- 单元/契约测试：状态路由、五项导航、旧 route 兼容、CN 提议与确认边界。
- 浏览器流程：服务启动 → 年度项目 → 产品/CN → 数据与核算。
- 视口：390 / 768 / 1440。
- 检查键盘访问、控制台错误、横向溢出和关键状态文案。

## 本轮完成定义

- Issue #71 已更新并处于进行中。
- 五项导航与首次进入状态在原型中可操作。
- 产品与设施不降级，CN Code 维护及导入差异在原型中可演示。
- 全年流程、监测计划、季度数据、计算与成本的原内容均有新入口或兼容入口。
- 自动化测试通过；浏览器检查记录分辨率与结果。
