# Portal 企业账号与演示角色浏览器验收（2026-11-28）

关联：#122、#13、#68。工作树：`fix/cbam-intake-qa-20261126`，尚未合入 `dev`。验收对象是本地 `http://127.0.0.1:4196/portal/` 与隔离 PostgreSQL 测试库，不代表生产发布。

## 可重复运行

启动 PostgreSQL 测试库、Portal 本地服务，以及开启 Chrome DevTools Protocol 9229 端口的 Chrome。设置 `DATABASE_URL` 后运行：

```bash
node qa/portal-customer-keyboard-check.cjs
node --test packages/platform/tests/portal-customer.test.cjs
```

浏览器脚本会创建两个随机测试租户。可以用 `PORTAL_URL` 和 `CHROME_CDP_URL` 指定不同的本地服务与调试端口；不要指向生产库。

## 验收结果

| 路径 | 结果 |
|---|---|
| 邮箱 Enter → 密码输入；模拟登录服务 503 后重试 | 保留密码步骤、显示明确错误；重试进入工作台并聚焦标题 |
| 键盘进入 CBAM → 空项目引导 → Space 确认企业 → 产品 CN 码 → 设施 → 核对 → 项目 | 全程可继续；步骤切换后的焦点落在新步骤标题；CN 码键盘加入后回到搜索框，保存后朗读结果；项目显示五项 CBAM 二级导航 |
| 生产关系提交模拟 503 → 重试 | 表单内容保留，错误可见；重试只保存一条关系 |
| 320 / 390 / 768 / 1440px CBAM 页面 | 主页面均无横向溢出；320px 当前服务入口保持可见 |
| 第一企业退出 → 第二企业进入 | 第二企业看到相同工作台模板，但无第一企业的项目、产品或设施；隐藏页面也已清空 |
| 演示复核角色 → 演示客户角色 → 真实企业 | 原有 11 个演示入口保留，演示 CBAM 五项导航可用；真实登录移除演示 URL 参数，刷新恢复真实租户及产品、设施、生产关系 |
| 已登录后服务端返回 401 | 返回登录、清除客户 token 与隐藏租户内容 |
| 服务端越权读写 | 伪造租户查询参数仍返回当前租户；借用他人项目新增被拒绝，跨租户修改返回 404，原记录未改变 |

## 实施修正

- 密码服务不可用或网络连接失败不再误导到“账号尚未开通”说明页；错误留在可重试的密码表单。
- 登录、项目引导、CN 码选择与保存、企业名称修改和取消编辑后的键盘焦点恢复。
- 项目 API 会话过期时统一清除客户页面与 token；从演示 URL 登录真实账号时清除演示路由参数。
- API 集成测试补足跨租户 GET、PUT、PATCH 的边界验证。
