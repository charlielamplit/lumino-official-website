# CBAM 材料计划草稿切片验收（2026-11-28）

基线：`dev` 合并提交 `8059842`。本切片位于 `feature/portal-material-request-authority`，未包含正式文件上传、模型任务或通知。

## 行为

- 企业负责人完成产品与设施的生产关系后，可为实际使用天然气的设施选择季度，建立天然气用量资料草稿。引导阶段不要求填写材料名称或邮箱。
- 服务端从登录会话解析租户，从年度项目取得年份，并校验设施和生产关系均属于当前租户、项目。标题、数据项和 `DRAFT` 状态由服务端生成；浏览器传入的租户字段不影响归属。
- 同一设施、季度和数据项重复提交返回同一记录；首次创建写入只追加审计。草稿在当前工作、年度概览和任务页显示为未发送，刷新后可恢复。
- 本机 E-02 演示文件和真实企业草稿没有互通。草稿不触发邮件、上传或模型提取。

## 验证

- PostgreSQL 集成测试：跨租户、无关联设施、无效季度、重复提交、API 伪造租户字段均被覆盖。
- Portal 浏览器回归：键盘完成引导和生产关系、创建草稿、刷新恢复；另一租户看不到第一租户的项目记录；320/390/768/1440px 无页面横向溢出。
- 完整确定性测试、语法和 `git diff --check` 通过。

## 下一门禁

正式客户文件进入系统前，还需要私有对象存储、服务端上传/下载授权、文件扫描、版本与摘要、数据处理与留存安排；随后才能把模型提取候选和具名确认接到这条服务端材料请求上。当前没有要求购买腾讯轻量存储服务器，优先评估私有 COS 存储桶。
