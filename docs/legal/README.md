# Lumino 隐私与数据文件

本目录是 Lumino 隐私、终端存储和客户内容许可的维护源。公开页面、表单勾选文案、合同附件和实际代码应与这里保持一致。

## 文件与用途

- `privacy-and-data-processing-notice.md`：面向官网访客、咨询联系人、试算用户和 Portal 用户的公开隐私说明源稿。
- `cookie-and-local-storage-notice.md`：当前 Cookie、`localStorage`、`sessionStorage` 和第三方脚本的公开清单及同意触发规则。
- `user-content-and-data-license-terms.md`：客户向 Lumino 提交材料、数据和文件时适用的内容与数据许可条款草案；建议纳入服务协议或 Portal 首次上传确认。
- `privacy-data-fact-register.md`：仅供内部使用的事实、责任人和上线前缺口登记，不应直接公开。

## 维护规则

1. 代码和部署配置是数据流事实来源，公开文本不得使用“可能使用”掩盖未核实状态。
2. 新增表单字段、第三方脚本、SDK、Webhook、邮件服务、外部托管、文件上传或本地存储键时，必须同步更新事实登记和公开说明。
3. 客户保留其原始材料和业务数据的权利；Lumino 只取得履行服务所需的有限许可。
4. 客户内容不得默认用于公开宣传、训练面向其他客户的通用模型、销售或无关产品开发。
5. 无法确认的事实进入内部登记，不以占位符形式发布。
6. 对外版本发布前，应由业务负责人、技术负责人和数据合规法律顾问共同确认。

## 当前适用范围

本组文件按中国运营主体、面向中国出口企业并可能服务欧盟相关业务的现状起草。它不是对所有国家法律的穷尽说明；新市场、新主体或新数据路径上线前应重新评估。
