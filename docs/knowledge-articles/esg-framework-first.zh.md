# ESG 报告：先定框架，还是先凑指标？

- 类型：方法指南
- 行业：通用制造
- 服务：ESG
- 更新：2026-10-30

## 一句话

先定**对谁说、用哪套框架、报告边界**，再采指标；反过来堆 KPI，最后几乎一定要返工。

## 建议顺序

1. **受众**：监管披露、客户问卷、融资方，还是内部管理？
2. **框架**：按受众选定 1 个主框架（或明确「问卷应答」而非完整报告）
3. **组织边界**：哪些法人、哪些工厂进范围
4. **议题优先级**：实质性议题 5–8 个，而不是 50 个指标齐头并进
5. **数据主人**：每个议题指定业务负责人与证据位置
6. **再采数、再写叙述**

## 常见返工原因

- 客户要的是问卷，却按完整年报结构硬写
- 边界中途扩大，历史数不可比
- 环境数据只有总部估算，工厂台账对不上

## 两周内能完成的最小集

- 一页：受众 + 框架 + 边界
- 一张表：优先议题、数据主人、缺口
- 三份已有材料：能耗、工伤、政策清单（有什么算什么，先标记缺口）

## 和碳盘查 / PCF 的关系

组织 GHG 与产品 PCF 可以给 ESG 环境章节供数，但**章节叙事和保证程度**仍要按 ESG 框架单独声明。

> 披露义务因司法辖区与上市身份而异。实务说明，不构成法律意见。
