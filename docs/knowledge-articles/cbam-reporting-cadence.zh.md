# CBAM 申报节奏：季度数据包和年度事项怎么排

- 类型：法规解读 · 实操
- 行业：钢铁 / 铝
- 服务：CBAM
- 更新：2026-10-30

## 一句话

工厂侧按**买方要数的期间**滚动准备数据包；不要把「季度沟通包」和「年度合规事项」混成一件事。

## 两层节奏

| 层级 | 常见内容 | 谁在催 |
|---|---|---|
| 季度 / 发运期 | 数量、编码、临时排放路径、Communication 包 | 欧盟进口商、贸易对接人 |
| 年度 | 监测计划一致性、设施年报、核查安排 | 合规、核查员、集团总部 |

## 工厂建议的日历（示意）

1. **每月**：产量、燃料、外购电热入账；异常当月标出
2. **每季末前 2–3 周**：对编码与发运清单；收前体回函；出季度包草稿
3. **买方确认后**：锁定该版本，改数走修订号，不覆盖旧包
4. **年末前后**：核对全年口径是否与各季一致；准备核查抽样清单

具体法定时点以进口商所在成员国与当期规则为准；上表是**工厂内部准备节奏**。

## 容易乱的三件事

- 用日历年产量直接套买方进口季，对不上提单
- 一季改工艺却不更新边界说明
- 年度核查要的「锁定快照」和日常沟通包版本搅在一起

## 最小可行分工

- 外贸：发运与编码
- 生产 / 能源：台账与计量
- EHS / 合规：边界、路径、版本与缺口
- 服务方：汇总成可交付包，并标明责任边界

> 法定申报由获授权申报人完成。本文是内部节奏建议，不构成法律意见。
