# Don’t reuse one spreadsheet for CBAM and PCF

- Type: Q&A
- Industry: steel / aluminium / manufacturing
- Service: CBAM · PCF
- Updated: 2026-10-30

## In one line

Both concern product-related emissions, but **rules, boundaries, purpose and recipients** differ. One sheet for both usually fails both.

## Contrast

| Dimension | CBAM (indicative) | PCF / ISO 14067 (indicative) |
|---|---|---|
| Purpose | Border adjustment / import support | Product disclosure / buyer request |
| Coverage | Listed codes and prescribed routes | Goal, functional unit, PCR / buyer spec |
| Recipient | Importer / declaration system | Brand, retail, EPD, etc. |
| Typical output | Communication / filing support pack | PCF report or statement |

## Reuse the foundations

Facility list, process notes, energy and output ledgers (align periods), supplier contacts.

## Keep separate

Boundaries and functional units, factor versions, assurance scope, and public wording.

> Follow current CBAM rules and the agreed PCF standard. Not legal advice.
