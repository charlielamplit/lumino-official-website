# CBAM 前体材料：哪些要拆、供应商怎么问

- 类型：方法指南
- 行业：钢铁 / 铝
- 服务：CBAM
- 更新：2026-10-30

## 一句话

很多「成品」的排放不在本厂，而在**外购前体**；不问清前体，实际值算不准，默认值也说不清为什么偏高。

## 先分清三类东西

| 概念 | 含义 | 工厂动作 |
|---|---|---|
| 本厂过程排放 | 本设施燃烧、工艺排放等 | 整理燃料、工艺气体、计量 |
| 外购前体 | 带入最终产品的中间材料 | 按采购批次追溯供应商 |
| 复杂货物 | 含多种前体 / 加工步骤 | 按规则拆分或按批准方法汇总 |

## 问供应商时，优先这五问

1. 供货品名与规格是否与我方采购批次一致？
2. 对应期间的产量 / 发货量口径是什么？
3. 排放是按实际监测还是行业默认？
4. 系统边界是否包含外购电热与关键辅料？
5. 能否提供可版本管理的声明或数据包（不是口头承诺）？

## 实操顺序

1. 从 BOM / 采购台账列出主要前体（按排放贡献排序，不要一次问遍全表）
2. 按供应商发统一问卷 + 模板
3. 回收后标记：可用 / 需澄清 / 暂用默认
4. 在交付包里写明每条前体的处理方式

## 卡点提示

- 贸易商转手多次，拿不到原厂数据 → 记录链条，必要时对该部分保留默认值
- 集团内部调拨也要当「外购」问清边界，不要默认「一家人不算」

> 前体范围与核算规则以当期 CBAM 实施要求为准。实务说明，不构成法律意见。
