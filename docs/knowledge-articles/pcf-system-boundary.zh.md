# ISO 14067：产品碳足迹的系统边界怎么定

- 类型：方法指南
- 行业：纺织 / 包装（制造企业通用）
- 服务：PCF
- 更新：2026-10-30
- 读者：被品牌要求提供产品碳足迹的工厂与供应链同事

## 一句话

还没算数之前，先写清三件事：**算哪个产品、算到哪一步、用什么功能单位**。边界一糊，后面的数据都会返工。

## 边界是什么（用大白话）

系统边界 = 这次核算「从哪儿开始、到哪儿结束、中间算哪些过程」。

常见两种：

| 说法 | 大概意思 | 什么时候常见 |
|---|---|---|
| 从摇篮到大门（cradle-to-gate） | 从原料到产品出厂 | 品牌 / 采购要供应商碳足迹时很常见 |
| 从摇篮到坟墓（cradle-to-grave） | 一直算到使用和废弃 | 更完整，但数据和责任更重 |

多数出口制造场景，**先把 cradle-to-gate 写死**就够用；客户若另有要求，再书面改边界。

## 定边界前必须锁死的四项

1. **产品对象**：哪个料号 / 哪类产品，不混算
2. **功能单位**：比如「1 吨产品」或「1 件成品」——后面所有数都除以它
3. **生命周期阶段**：原料、运输、生产、外发加工……哪些进、哪些出
4. **截断规则**：太小的流是否忽略，忽略标准写清楚

## 工厂侧容易踩的坑

- 功能单位口头说了，文件里没写死
- 外发染厂 / 外协工序算不算，各方理解不一致
- 蒸汽、电按车间汇总，对不上单个产品
- 客户模板要「到大门」，你却按全生命周期去凑

## 建议动作（3 步）

1. 与客户书面确认：边界类型 + 功能单位 + 期间
2. 列出进边界的过程清单（含外协）
3. 再发采集表——**先边界，后填数**

## 法规 / 标准锚点

- ISO 14067（产品碳足迹量化）
- 客户指定的 PCR / 行业规则（如有）
- 具体方法选择以项目约定与适用标准版本为准
