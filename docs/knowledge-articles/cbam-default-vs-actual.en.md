# CBAM: default values or actuals?

- Type: Q&A
- Industry: steel / aluminium
- Service: CBAM
- Updated: 2026-10-30

## In one line

Defaults can bridge gaps; buyers and long-term cost usually prefer **actuals**. The point is to state the path, gaps and evidence — not to mix silently.

## When each path fits

| Path | Better when | Watch-outs |
|---|---|---|
| Default | Large data gaps, first trial filings | Often higher emissions; buyers ask for a switch plan |
| Actual | Stable process, complete ledgers, precursor data | Lock period, boundary and metering; keep versions |

## Ready for actuals?

1. Product and CN codes match the buyer’s import view
2. Facility / line boundary is written down
3. Fuel, purchased heat/power and output reconcile to bills or meters
4. Main precursors have statements — or gaps are listed

If one or two items are missing: deliver defaults **plus a gap list and switch plan**.

## Three sentences to write

1. This period uses default / actual (or mixed by code)
2. Key source files and versions
3. When you expect to switch, and what is still missing

> Default factors follow the current implementing rules. Practical guidance only — not legal advice.
