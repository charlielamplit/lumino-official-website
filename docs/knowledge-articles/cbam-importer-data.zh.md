# CBAM 正式期：进口商要什么，工厂先准备什么

- 类型：法规解读 · 实务
- 行业：钢铁 / 铝（也适用于其他覆盖品类）
- 服务：CBAM
- 更新：2026-10-30
- 读者：工厂 EHS、外贸、集团合规协调人

## 一句话

欧盟这边通常由**进口商**去申报；你这边工厂要做的，是按时交出**说得清、对得上、留得住证据**的产品与设施数据。

## 谁干什么

| 角色 | 主要责任 |
|---|---|
| 欧盟进口商 / 申报人 | 向主管机关申报 |
| 出口工厂 / 前体供应商 | 提供产品、设施、能源与材料数据及证明 |
| 服务方（如 Lumino） | 帮你把范围、采集、计算和交付包组织好——**不替代**进口商申报 |

## 进口商常会要的五类东西

1. **产品与编码**：品名、CN/HS、数量、所属期间（以买方进口口径为准）
2. **设施与工艺**：哪个厂、哪条线、什么工艺路径
3. **活动数据**：产量、燃料、外购电热、关键前体
4. **排放路径说明**：用实际值还是默认值，缺口与假设写清楚
5. **证据**：账单、声明、计量说明、文件版本——不只发截图

## 工厂建议先做的五步

1. 列出出口产品清单和编码依据
2. 画清厂区 / 设施与主要产线
3. 整理近几个月的产量、燃料、外购电热台账
4. 列出前体采购和已有供应商声明
5. 对照进口商模板，标出缺口和可交付日期

## 先别纠结的事

- 不必一上来就背完整法条
- 免费配额、原产国碳价抵扣等完整情形，放在项目里按**当期规则**再确认
- 一批货跨多个编码时，**分开算**，不要取平均

## 法规锚点

- Regulation (EU) 2023/956 及后续修订 / 实施条例（以申报期适用版本为准）
- 具体字段以进口商模板与当期实施细则为准

已有进口商模板或明确时限时，把产品、去向和模板发来，我们回复适用服务与资料清单。
