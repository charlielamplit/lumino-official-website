## 发布规则

1. `UNVERIFIED` 声明不得出现在公开页面；表中保留 CLM-011 仅用于记录明确禁用的表述。
2. 法规数字、标准适用性、编码、资质、客户案例和效果数字必须在发布前增加来源、适用日期和责任人。
3. `PLANNED` 一律使用未来时态，且主要操作只能是咨询或查看计划。
4. 声明变化必须先更新本登记表和公共服务注册表，再更新页面文案。
