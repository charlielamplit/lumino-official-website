# 试算器 CBAM 数据来源

## 默认值（正式期，含加价）

- **法规**：欧委会实施条例（EU）2025/2621，经（EU）2026/1740 校正
- **欧委会信息用 Excel**：`DV correcting act_final update_06.08.xlsx`
  - 发布日：2026-08-10
  - 文件版本：v2 / 2026-08-06
- **本地文件**：`0_法规核心文档/欧盟CBAM默认值定值.xlsx`
- **归档（校正前）**：`0_法规核心文档/欧盟CBAM默认值定值_2025-2621_v1_archived.xlsx`
- **说明**：Excel 为信息用途；具有法律约束力的数值以实施条例文本为准。

## 可选取 CN / TARIC 编码

- **英文品名**：英国 Trade Tariff API 税号树（CN 结构），按可选编码组合
- **中文品名**：海关用语词表 + 特征短语，去空格与中英混杂标点；重名时以编码后缀区分，保证一码一名
- **覆盖范围**：附件 I HS 品目下展开的 8 位 CN，以及附件单独列出的 10 位 TARIC

## 界面展示元数据

- `data/data-version.json`：供试算页展示的数据包版本与法规引用
