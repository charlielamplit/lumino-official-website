# 出口相关新规速览：EUDR 与 CSDDD 工厂先备什么

- 类型：法规解读 · 实务
- 行业：木材 / 橡胶 / 农产品供应链 · 通用制造
- 服务：出口合规 / export
- 更新：2026-11-02

## 一句话

EUDR 抓的是**特定商品的毁林与可追溯**；CSDDD 抓的是**公司层面的尽职管理与价值链责任**。两者都可能传导到中国出口商，但准备材料不完全一样。

## 两个制度怎么区分

| | EUDR（欧盟零毁林） | CSDDD（企业可持续尽职管理） |
|---|---|---|
| 核心问题 | 这批货是否与毁林/退化无关、能否追溯到地块 | 公司是否建立尽职管理、识别并处理人权与环境不利影响 |
| 典型对象 | 牛、可可、咖啡、棕榈油、橡胶、大豆、木材等（以正式清单为准） | 达到规模门槛的公司及其价值链（门槛与时间表以正式文本为准） |
| 工厂最常被要的 | 地理定位、权属/采伐证明、供应链地图、风险缓解说明 | 政策与流程、供应商行为准则、风险评估与申诉渠道证据 |
| 和碳足迹关系 | 不是 PCF；但客户可能同一问卷里一起问 | 环境议题可能包含气候，但范围远大于产品碳 |

## 若你在 EUDR 相关供应链里

1. 先核对产品是否落入覆盖商品及衍生情形（含贸易商路径）
2. 向上游要：**地块坐标 / 生产区域、合法权属、采伐或收获期**
3. 建批次级追溯：哪批原料进哪批成品
4. 保留可导出的尽职声明支持材料（按买方模板）

## 若客户按 CSDDD / 尽职管理来催

1. 问清对方要的是「填问卷」还是「签承诺 + 抽查」
2. 准备最小包：人权与环境政策、关键供应商清单、风险评估结果、纠正与申诉入口
3. 高风险品类优先做现场或文件审核计划，不要只回「我们合规」

## 四周行动清单（出口工厂通用）

1. 标出对欧客户与可能受影响的品类
2. 画一级供应商地图（国家 / 地区）
3. 缺坐标或权属证明的原料列缺口表
4. 指定合规接口人，统一对外口径（避免销售与 EHS 各回各的）

> 覆盖范围、生效与过渡安排以欧盟正式条例及主管部门指南为准，且可能调整。本文为实务入门，**不构成法律意见**；重大合同与清单判定请咨询合格律师或合规顾问。
