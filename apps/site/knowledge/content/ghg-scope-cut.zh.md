# 组织层面：Scope 1 / 2 和常见 Scope 3 怎么切

- 类型：方法指南 · 实务问答
- 行业：通用制造
- 服务：企业碳盘查（GHG）
- 更新：2026-10-30
- 读者：第一次做组织碳盘查、或要填客户碳排放问卷的同事

## 一句话

先分清：**厂界内自己烧的、自己买的电热、以及供应链上下游**。切错类，后面指标和问卷会对不上。

## 三张「桶」

| 类别 | 大白话 | 工厂里常见例子 |
|---|---|---|
| Scope 1 | 自己直接排的 | 锅炉燃煤/燃气、厂内车辆燃油、制程逸散 |
| Scope 2 | 买进来的电、热、冷、蒸汽带来的间接排放 | 外购电、外购蒸汽 |
| Scope 3 | 上下游其它间接排放 | 外购原料、上游运输、员工通勤、产品运输等 |

> 名称来自 GHG Protocol 企业标准的常用分类；具体是否核算某一类 Scope 3，看你的报告目的和客户要求。

## 怎么切：三个问题

1. **排放发生在谁的组织边界里？** 自有锅炉 → 多半 Scope 1；电网购电 → Scope 2。
2. **是不是你买来的能源载体？** 买电 / 买蒸汽 → 看 Scope 2 规则。
3. **是不是价值链上别人的活动？** 供应商生产原料、物流承运 → 常见进 Scope 3。

## 中国工厂问卷里最常被问的 Scope 3

不必一次算完所有 15 类。优先看客户点名的，例如：

- 外购商品与服务（原料）
- 上游运输与配送
- 燃料和能源相关活动（有时与 1、2 配套出现）
- 下游运输（若客户要）

其余类别可以列入「明年再扩」——**写进计划，而不是假装已经算完**。

## 常见误会

- 把外购电算进 Scope 1
- 把供应商排放和自己 Scope 1 混在一张表里不标注
- 组织盘查（公司总排放）和产品碳足迹（单个产品）当成一回事

## 建议顺序

1. 画组织边界（哪些法人 / 厂区进盘查）
2. 先完成 Scope 1 + 2，数据质量稳住
3. 按客户或披露要求，挑选 Scope 3 类别
4. 每类写清数据来源与缺口

## 法规 / 标准锚点

- GHG Protocol《企业核算与报告标准》
- ISO 14064-1（组织层面）等（按项目选用）
- 客户问卷或交易所 / 监管披露要求（如适用）

## 什么时候该找我们

客户问卷来了、但不知道从 Scope 几填起，或 1/2 和产品碳足迹搅在一起时，把问卷和厂区说明发来即可。
