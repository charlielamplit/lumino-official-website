# 产品碳足迹：活动数据怎么采、证据怎么留

- 类型：方法指南
- 行业：纺织 / 包装 / 电子
- 服务：PCF
- 更新：2026-11-02
- 读者：EHS、供应链、产品工程师

## 一句话

边界定完之后，PCF 成败在**活动数据能不能对上证据**；先建「最小采集清单」，再谈因子精不精。

## 建议按这四类采

| 类别 | 典型数据 | 常见证据 |
|---|---|---|
| 材料投入 | 主材、辅材、包装克重与损耗 | BOM、采购入库、称重记录 |
| 能源与公用工程 | 电、蒸汽、燃料、压缩空气分摊 | 账单、表计、产线分摊说明 |
| 运输（若在边界内） | 运距、载重、运输方式 | 运单、物流合同摘要 |
| 废弃与循环 | 边角料去向、回收比例 | 危废联单、回收协议 |

## 采集顺序（两周可跑通）

1. 锁定 1–2 个代表 SKU 与功能单位
2. 列出边界内过程清单（含外协）
3. 给每个过程指定数据主人与证据位置
4. 先收「有什么算什么」，缺口单独列表，不空着糊弄
5. 核对单位、期间、是否含税/是否含库存调整

## 质量自检三问

1. 同一期间的产量，能不能对上入库或销售口径？
2. 能源分摊是产线实测、工时比例，还是全厂平均？写清楚。
3. 供应商数据是声明、检测，还是行业平均？版本号在哪？

## 先别做的事

- 一上来全品类铺开采集
- 用未注明版本的网络排放因子直接对外披露
- 把组织盘查的全厂总数直接除以产量当产品足迹（边界通常对不上）

> 方法与披露以约定的 ISO 14067 / PCR / 客户规范为准。实务说明，不构成保证或法律意见。
