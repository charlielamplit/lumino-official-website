# 组织温室气体盘查：首年从哪里起步

- 类型：方法指南
- 行业：通用制造
- 服务：碳盘查 / inventory
- 更新：2026-11-02
- 读者：EHS、能源、管理层协调人

## 一句话

首年目标不是「一次算到完美」，而是**边界清楚、Scope 1/2 站得住、Scope 3 有优先级**，并能在明年复算。

## 首年最小范围（建议）

| 模块 | 首年建议 | 说明 |
|---|---|---|
| 组织边界 | 先定运营控制或股权比例，写进一页纸 | 中途改边界会毁掉同比 |
| Scope 1 | 固定燃烧 + 移动源 + 有数据的过程排放 | 先抓大头燃料 |
| Scope 2 | 外购电（市场法 / 位置法按披露要求选） | 账单期间对齐报告年 |
| Scope 3 | 只做 2–4 类高相关类别 | 例如外购商品、上游运输、商务旅行 |

## 六个落地步骤

1. 书面确认组织边界与报告年
2. 拉出设施与能源账户清单
3. 收集燃料与电费账单，统一单位
4. 选因子库并记录版本
5. 识别 Scope 3 优先类别与数据缺口
6. 出内部盘查底稿 + 管理层可读摘要（不是长篇年报）

## 和 PCF / CBAM 的分工

- 组织盘查：回答「公司今年排了多少」
- PCF：回答「单位产品排了多少」
- CBAM：回答「出口到欧盟的清单产品如何支持申报」

底层能源台账可以共享，**结论页不要混用**。

## 首年常见卡点

- 租用厂房的边界归属扯皮 → 按控制权原则先落一版并备注争议
- 只有金额没有实物量 → 先用量，金额法放次优先类别并披露局限
- 想一年做完全部 15 类 Scope 3 → 几乎必失败

> 方法学常见参照 GHG Protocol；法定披露以适用辖区要求为准。实务说明，不构成法律意见。
