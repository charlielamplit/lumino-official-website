DATA ARCHITECTURE

原始资料不是结论，Agent 建议也不是事实。

平台用分层和版本把“来自哪里”、“怎样处理”和“谁确认”分开记录。

01

原始资产

原文件、数据集与业务主档，保留不可变版本。

02

服务绑定

记录服务、案件、对象、用途、期间和可见范围。

03

正式事实

Agent 只生成提议，授权人员确认后形成特定服务事实。

04

计算快照

锁定资产版本、转换、规则包和参数版本。

05

报告与交付

经复核、审批和锁定后进入正式交付，历史可重现。

CONTROL MODEL

很多工作可以自动化，专业责任不能自动化。

AGENT

最小数据范围

只读取当前企业、当前服务与当前用户有权访问的数据。

CALCULATION

确定性与可复现

正式计算不依赖不可解释的生成式结果。

REVIEW

复核与职责分离

制备、复核、审批与锁定是可审计的不同动作。
